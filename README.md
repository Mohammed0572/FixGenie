# FixGenie

A full-stack application built with React, FastAPI, and Python.

## Technologies

- **Frontend:** React, Vite
- **Backend:** Python, FastAPI, SQLite
- **Machine Learning:** Scikit-learn models for bug classification and severity prediction

## Getting Started

### Backend Setup
1. CD into the `backend` directory.
2. Create a virtual environment: `python -m venv venv`
3. Activate the environment: `venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Run the server: `python main.py` or use uvicorn directly.

### Frontend Setup
1. CD into the `frontend` directory.
2. Install dependencies: `npm install`
3. Start the Vite dev server: `npm run dev`
